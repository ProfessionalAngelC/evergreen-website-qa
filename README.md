# Evergreen Website QA

Manual and automated QA testing of a real business website using test cases, defect reports, regression testing, and Playwright.

## Project Overview

This project documents quality assurance testing performed on the customer-facing website of WA Evergreen Insulation LLC.

The website is provided through Housecall Pro's website service and is tested as a black-box application. Testing does not require access to the website's source code.

The purpose of this project is to practice and demonstrate a structured software QA process using a real production website.

## Testing Scope

The project will include:

* Functional testing
* Exploratory testing
* Negative testing
* UI and responsive testing
* Cross-browser testing
* Regression testing
* Defect documentation
* Automated browser testing with Playwright
